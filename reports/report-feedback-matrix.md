# Next mode
จากความเห็นข้างต้น ความเห็นว่า
- "ความต้องการพื้นที่จอดมอเตอร์ไซค์แบบกระจายตัวหลายจุด มากกว่าการรวมไว้จุดเดียว (สมปอง)"
- "เสี่ยงต่อการมักง่ายจอดซ้อนคันบริเวณหัวมุมหรือจุดตัดทางแยก หากไม่มีรั้วกั้นที่ชัดเจน (สมปอง)"
น่าสนใจและอาจเป็นปัญหาในอนาคตหากไม่แก้ไข เราจึงต้องการทำ **Empathize** ใหม่ในส่วนหัวข้อแรก และ เอาความเห็นที่ 2 ไป **Ideate** กันใหม่ เพื่อไม่ให้เกิดปัญหาเหล่านี้อีก หากมีการใช้แบบลานจอดรถนี้จริง
